## Project summary

Agentic system that removes hardcoded and manually created prerequisite test data from Selenium (Java, TestNG) and Playwright suites for the Znode platform. First-layer agents (Framework scanner, AIO scanner, DB data profiler, KB scanner) produce a requirements JSON of typed data keys. Second-layer agents (DB scanner + query builder, API Stoplight scanner + payload builder) build cached queries and API collections. A deterministic resolver supplies data to tests before the suite runs.

## Glossary

| Term | Meaning |
| --- | --- |
| Data key | Vocabulary identifier for a type of test data, such as `PRODUCT_SIMPLE_IN_STOCK` |
| Requirements JSON | Map from each test to the data keys it needs |
| DB entity map | Cached map of entities, tables, joins and property columns |
| Query repository | Approved DB queries per data key |
| Collection repository | Approved API collections per data key |
| Fitness check | Validation that fetched data is usable (for example, visible on storefront) |
| Lease | Exclusive hold on a consumable record during one test |
| Drift | Existing test data that no longer meets its conditions |
